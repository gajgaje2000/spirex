# Weather App

Real-time weather forecast web application built using HTML, Tailwind CSS, and JavaScript that dynamically fetches temperature, humidity, wind speed, and atmospheric conditions from a live weather API.

## Overview
- Developer: Jenish Gajera
- Task: Task 10 - Weather App

## Structure
- `index.html`: Search bar, weather metrics cards, and responsive card layout
- `css/style.css`: Font definitions and custom base styles
- `js/app.js`: Live weather data fetching, geocoding integration, WMO weather code mapping, and dynamic DOM updates
