# Country Information App

Interactive country information web application built using HTML, Tailwind CSS, and JavaScript that dynamically displays country flags, capitals, populations, regions, and currencies.

## Overview
- Developer: Jenish Gajera
- Task: Task 9 - Country Information App

## Structure
- `index.html`: Search bar and country detail card layout
- `css/style.css`: Font definitions and custom base styles
- `js/app.js`: Data fetching, multi-field search algorithms, and DOM rendering
