# Job Portal UI

A responsive job-search interface where users can browse verified job listings, search and filter opportunities across locations, categories, and experience levels, view comprehensive job details, save bookmarks, and apply online using HTML, CSS (Tailwind), and JavaScript.

## Overview
- Developer: Jenish Gajera
- Task: Task 15 - Job Portal UI

## Architecture & Structure
- `index.html`: Responsive job portal layout with unified search filters, category quick-pills, dynamic job card grid, and native modal dialogs
- `css/style.css`: Clean typography styling with Google Font Plus Jakarta Sans and scroll containment for dialog backdrops
- `js/app.js`: Pure JavaScript client logic for multi-criteria filtering, sorting, bookmarking, application submissions, and localStorage persistence
