# Restaurant Website

An attractive restaurant website that displays the culinary menu, dining services, ambiance photo features, contact details, operating hours, and an interactive online table-booking interface using HTML, CSS (Tailwind), and JavaScript.

## Overview
- Developer: Jenish Gajera
- Task: Task 16 - Restaurant Website
- Concept: The Olive Bistro (Contemporary Mediterranean & Wood-Fired Fusion Dining, Surat)

## Architecture & Structure
- `index.html`: Responsive single-page restaurant portal with sticky navigation, seasonal menu filters, services overview, atmosphere gallery, table reservation interface, and operating hours
- `css/style.css`: Clean typography styling with Google Font Plus Jakarta Sans and scroll containment for dialog backdrops
- `js/app.js`: Pure JavaScript client logic for menu category filtering, interactive time slot selection, real-time reservation preview, booking ticket generation, and localStorage persistence
