# Restaurant Website

A restaurant website that displays the menu, services, photo gallery, contact details, and online table-booking interface using HTML, CSS (Tailwind), and JavaScript.

## Overview
- Developer: Jenish Gajera
- Task: Task 16 - Restaurant Website

## Architecture & Structure
- `index.html`: Responsive restaurant website with navigation, menu filters, services section, photo gallery, table booking form, and contact hours
- `css/style.css`: Typography styling with Google Font Plus Jakarta Sans and dialog scroll containment
- `js/app.js`: Client logic for menu category filtering, time slot selection, live booking summary, and localStorage persistence
- `assets/images/`: Local restaurant and food photos
