# Shopping Cart

Dynamic e-commerce shopping cart web application built using HTML, Tailwind CSS, and JavaScript that allows users to add or remove products, manage quantities, and automatically calculate order totals.

## Overview
- Developer: Jenish Gajera
- Task: Task 11 - Shopping Cart

## Structure
- `index.html`: Product catalog, interactive cart management interface, and order summary layout
- `css/style.css`: Font definitions and custom base styles
- `js/app.js`: Product catalog rendering, state management, quantity adjustment, custom product creation, and dynamic price calculation
