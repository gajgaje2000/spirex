# College Management Frontend

A college website interface for displaying departments, courses, faculty, students, events, and other institutional information using HTML, CSS (Tailwind), and JavaScript.

## Overview
- Developer: Jenish Gajera
- Task: Task 13 - College Management Frontend

## Architecture & Structure
- `index.html`: Accessible tabbed portal interface with overview, academic departments, faculty directory, student roster, and events noticeboard
- `css/style.css`: Clean typography styling with Google Font Plus Jakarta Sans and smooth antialiasing
- `js/app.js`: Dynamic client-side logic managing accessible tab switching, real-time student search and filtering, faculty department filters, category-based event views, and localStorage data persistence for student registration
