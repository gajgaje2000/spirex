# Expense Tracker

Minimalist expense tracker web application built using HTML, Tailwind CSS, and JavaScript that allows users to add, view, and delete expenses while dynamically calculating the total.

## Overview
- Developer: Jenish Gajera
- Task: Task 8 - Expense Tracker

## Structure
- `index.html`: Card markup, total spent display, expense input form, and expense list
- `css/style.css`: Font definitions and custom base styles
- `js/app.js`: State management, dynamic total calculation, delete handlers, and localStorage persistence
