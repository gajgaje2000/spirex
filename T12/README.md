# Hospital Appointment Website

A user-friendly, multi-page healthcare website that allows patients to explore clinical services, view certified doctors, and book appointments using HTML, CSS (Tailwind), and JavaScript.

## Overview
- Developer: Jenish Gajera
- Task: Task 12 - Hospital Appointment Website

## Architecture & Structure
- `index.html`: Hospital home page featuring emergency stats, clinical services preview, and featured doctors
- `services.html`: Comprehensive clinical departments overview with consultation fees and treatment details
- `doctors.html`: Specialist doctors directory with department filtering, qualifications, and direct booking links
- `appointment.html`: Interactive appointment booking form with URL parameter pre-filling and localStorage persistence
- `css/style.css`: Google Font Plus Jakarta Sans configuration and smooth antialiasing
- `js/app.js`: Unified script managing responsive navbar toggles, doctors filtering, appointment state, and URL parameter handling
