# Hospital Appointment Website

A minimal, clean healthcare web application that allows patients to view doctors, check available services, and book appointments using HTML, CSS, and JavaScript.

## Structure
- `index.html`: Available services, doctor list, booking form, and scheduled appointments
- `css/style.css`: Font definitions and custom base styles
- `js/app.js`: Doctor selection, appointment scheduling, and localStorage persistence
