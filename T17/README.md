# Online Book Library

A web-based library system developed using HTML, CSS (Tailwind), and JavaScript that allows users to browse, search, borrow, return, and manage books online.

## Overview
- Developer: Jenish Gajera
- Task: Task 17 - Online Book Library

## Architecture & Structure
- `index.html`: Accessible book catalog interface with search controls, filters, and native modal dialogs for adding, borrowing, and viewing books
- `css/style.css`: Typography styling with Google Font Plus Jakarta Sans and dialog scroll containment
- `js/app.js`: Client logic handling real-time search, category/availability filtering, sorting, borrow/return state, and localStorage persistence
