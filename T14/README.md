# Student Internship Portal

A web portal where students can explore internships, view detailed role specifications, submit applications online, and track submitted applications using HTML, CSS (Tailwind), and JavaScript.

## Overview
- Developer: Jenish Gajera
- Task: Task 14 - Student Internship Portal

## Architecture & Structure
- `index.html`: Accessible tabbed portal layout featuring internship discovery, live filters, application tracker, and native accessible modal dialogs
- `css/style.css`: Modern typography styling with Google Font Plus Jakarta Sans and scroll containment for dialog backdrops
- `js/app.js`: Dynamic client-side logic for real-time keyword search, domain/work-mode filtering, native dialog handling, and localStorage persistence for submitted applications
